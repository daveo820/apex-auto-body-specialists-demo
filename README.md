# Apex Auto Body Specialists: concept demo

Hand coded static concept site by LuminArch for Apex Auto Body Specialists (Apex, NC). Not an official site. `noindex`, robots Disallow.

- Live: https://apex-auto-body-specialists-demo.vercel.app/
- Build: `python3 build.py` writes the HTML pages. No framework, no build step on Vercel.
- Docs: `market-research.md`, `FACTS_LOG.md`, `DESIGN_DNA.md`. Competitor screenshots in `research/`.
- Fonts: Chakra Petch and Source Sans 3 (SIL OFL), self hosted in `fonts/`.
